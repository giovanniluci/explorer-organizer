# Launch checklist

## Before day 1

- [ ] Release v1.0.0 is published, both downloads work on a clean Windows 10 and 11 machine (or VM)
- [ ] README renders on GitHub: logo, badges, GIF, download button
- [ ] Social preview uploaded (Settings → General → Social preview → `assets/social-preview.png`)
- [ ] Discussions enabled, with categories *Q&A*, *Ideas*, *Show your rules*
- [ ] 5–8 issues opened from the roadmap, of which 3–4 labelled `good first issue` and `help wanted`
      (e.g. "Add German translation", "winget manifest", "Preset: Screenshots folder", "7z extraction")
- [ ] Private vulnerability reporting enabled (Settings → Security)
- [ ] Notifications on for issues, PRs and Discussions (GitHub mobile app)
- [ ] 2–3 hours blocked in your calendar after each post

## First 48 hours

**Every 1–2 hours while awake**
- [ ] Reply to every HN / Reddit / PH comment, including critical ones, with thanks and facts, never defensively
- [ ] Triage new issues within a few hours: label (`bug`, `enhancement`, `question`), reproduce, reply
- [ ] Move "how do I…" questions to Discussions and answer them there

**Day 1 evening**
- [ ] Fix any crash or install bug immediately and ship `v1.0.1` (bump `Directory.Build.props`, CHANGELOG, tag)
- [ ] Turn good suggestions into issues and thank the author by @mention

**Day 2**
- [ ] Post on the next subreddit (one per day, never cross-post the same text)
- [ ] Pin a Discussion "What rules do you use?" and share your own setup
- [ ] Update the README FAQ with questions asked more than once

## Week 1–2

- [ ] Weekly "What's new" in Discussions if anything shipped
- [ ] Merge first community PRs quickly and credit contributors in CHANGELOG
- [ ] Product Hunt launch (see `product-hunt.md`)
- [ ] Consider a `winget` submission once v1.0.x is stable

## Never

- Buying stars or upvotes, asking friends to upvote, sock-puppet accounts
- Automated or repeated posting across communities
- Claims you can't back up with the code or `docs/feature-matrix.md`
