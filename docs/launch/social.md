## LinkedIn (post with `assets/tour.gif` or `assets/social-preview.png`)

> I just released my first open-source desktop app: **Explorer Organizer**, a rule-based file organizer for Windows.
>
> The problem: Downloads and Desktop fill up with invoices, screenshots and installers, and cleaning them is a weekly chore.
>
> The approach:
> • IF/THEN rules on file type, name, dates, photo/music metadata, even text inside PDFs and Office files
> • triggered by drag & drop, Explorer's context menu or real-time folder watching
> • a preview before anything moves, and undo for the last 50 runs
> • fully offline: no account, no cloud, no telemetry
>
> Tech: C# 12, .NET 8, WPF, xUnit with UI Automation tests, Inno Setup, GitHub Actions releases with SHA-256 checksums.
>
> It's free and MIT-licensed. Feedback, issues and contributions are welcome 👇
> https://github.com/giovanniluci/explorer-organizer
>
> #opensource #windows #dotnet #productivity
